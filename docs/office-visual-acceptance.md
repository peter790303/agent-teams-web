# AI Office 視覺驗收清單

本清單以產品提供的 AI OFFICE 參考圖為基準，供前端實作與後續驗收使用。

- [ ] 深色頁首顯示產品名稱與版本、即時時間／日期、系統狀態與主控身份。
- [ ] 桌面版使用約 70% 辦公室場景與約 30% Command Center 的左右配置，畫面不留大塊空白。
- [ ] 辦公室場景具備綠色磁磚地板、牆體隔間、AI 主控室、會議室、休息區與主管辦公室。
- [ ] 場景包含桌椅、螢幕、鍵盤、植物、飲水機、書架與一致的像素風人物，不使用 emoji 代替人物。
- [ ] Command Center 提供功能 tabs、即時動態、今日統計、系統資源與待處理區；沒有 API 的數值顯示「資料未提供」，不捏造進度或健康數字。
- [ ] 底部員工卡片顯示實際 API 狀態；未取得狀態時保持未知／尚無資料，不呈現假綠色進度。
- [ ] 窄版可將 Command Center 移到場景下方，辦公室與卡片仍可使用。
- [ ] 既有任務建立、任務 detail、模型設定路由與 repository API 維持可用；瀏覽器直接連 Nest API，不新增 server proxy。
